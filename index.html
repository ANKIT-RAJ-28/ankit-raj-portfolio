Optima Inbound Agents (Conversational AI & MIP Engine)

LangGraph Mixed-Integer Programming Databricks

PROBLEM

An 8-week legacy logistics planning cycle forced a €1 billion transport network to run on stale data and manual spreadsheets, leading to massive capital bleed via deadhead miles and underutilized assets.

PRODUCT THINKING

Democratize operational research. Do not let LLMs perform raw math. Use a deterministic MIP solver to calculate optimal routes, and deploy a multi-agent Generative AI orchestrator as a cognitive read-engine over the results.

EXECUTION

Deployed a LangGraph Supervisor routing natural language to specialized ReAct sub-agents. Enforced strict Token Budgets per Turn (bounded 50-row sampling) and a Zero-Trust SP-Only identity model to maintain sub-second latency.

IMPACT

  • Collapsed the 8-week manual cycle to a daily automated run.
  • Targeting 4.5% structural cost reduction on €1B+ inbound spend.
  • Eradicated the "SQL Gatekeeper" delay, dropping query response times to ~30 seconds at €0.15 per conversational turn.

Warranty Claims Clustering (WCC) Intelligence Engine

Claude 3.5 Sonnet HDBSCAN / UMAP Palantir Foundry

PROBLEM

17,300+ unclassified multi-lingual warranty claims daily completely overwhelmed analysts. Brittle regex rules led to a 90-120 day defect detection lag, compounding into a $180M+ annual liability.

PRODUCT THINKING

Replace rigid taxonomies with unsupervised density clustering. Solve 'symptom conflation' by decoupling hardware extraction (OEM part numbers) from defect severity (safety-critical tiers).

EXECUTION

Architected a Two-Agent pipeline (Component Specialist + Defect Specialist). Translated outputs into 384-dimensional dense vectors, compressed via UMAP, and clustered using Two-Level HDBSCAN inside Databricks.

IMPACT

  • Slashed defect detection cycle time from 90 days to under 48 hours.
  • Enabled immediate Tier-1 supplier chargebacks, yielding $4.5M - $8.2M in annual savings.
  • Achieved >400x ROI with an optimized cloud compute OPEX of ~$957/month.

Clinical Orderset Automation MVP

RAG Pipeline Parallel AI Processing Clinical Governance

PROBLEM

Manually transcribing complex 500-page clinical trial protocol PDFs into structured EHR ordersets took days, burdening medical staff and carrying massive liability risks due to human data-entry errors.

PRODUCT THINKING

Controlled automation. The AI acts exclusively as a drafting and flagging assistant, not an autonomous decider. Couple probabilistic LLM extraction with rigid, deterministic Python schema validation.

EXECUTION

Built a Hub-and-Spoke Agent Orchestrator initiating 7-way parallel LLM extraction calls to slash latency. Implemented RAG to ground every extracted row to an exact PDF source snippet and page number.

IMPACT

  • Reduced pure AI processing time from 140s to ~20s; end-to-end processing under 5 minutes.
  • Achieved 100% safety gate effectiveness with zero critical failures bypassing review.
  • Slashed clinician review time by ≥50% using split-screen validation UI.

Yield Curve Cleansing (YCC) AI Platform

Exception Management SOC Compliance Financial Ops

PROBLEM

Valuations required cleansing 180+ multi-vendor yield curves under strict hourly deadlines (1 PM - 5 PM). Legacy macro tools caused severe latency, knowledge silos, and lacked audit trails.

PRODUCT THINKING

Reject full-automation; maintain human-in-the-loop for asymmetric market intelligence. Let an AI rules engine absorb the healthy 85% of volume, focusing the human exclusively on the 15% volatile anomalies.

EXECUTION

Deployed a multi-agent framework: an Ingestion Gateway for normalization, an Anomaly & Drift agent to flag exceptions, and a RAG-based LLM Reason-Drafter to suggest override justifications from historical data.

IMPACT

  • 100% decommissioned the legacy macro tool across global trading desks.
  • Enabled 10 analysts to effortlessly clear 180+ curves in minutes without SLA breaches.
  • Established an immutable, SOC-compliant 4-eyes sign-off process for vendor overrides.
